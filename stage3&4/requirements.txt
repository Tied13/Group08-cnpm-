Môi trường cài đặt và thư viện Python: Mỗi thành viên mở Terminal chạy lệnh python -m pip install Flask pyodbc để đảm bảo cài đúng vào phiên bản Python đang chọn trong VS Code. Để kết nối được với SQL Server qua pyodbc, máy tính bắt buộc phải có driver hệ thống ODBC Driver 17 (hoặc 18) for SQL Server.

Cấu hình CSDL và khởi chạy hệ thống: Trước khi chạy chương trình, mỗi người mở SSMS, kết nối máy chủ cá nhân, mở file init_database.sql và bấm Execute (F5) để khởi tạo CSDL CourseRegistrationDB. Khi mở code, mỗi thành viên tự sửa dòng DB_SERVER trong file config.py cho đúng với tên máy chủ trên SSMS của máy mình (ví dụ localhost, ., hoặc DESKTOP-ABC\SQLEXPRESS) và tuyệt đối không đẩy file cấu hình cá nhân này lên GitHub. Sau khi chuẩn bị xong, mở Terminal gõ python app.py và truy cập trình duyệt tại [http://127.0.0.1:5000](http://127.0.0.1:5000).

Quy tắc vận hành Git và quản lý mã nguồn: File .gitignore phải chứa sẵn __pycache__/ và *.pyc để không đưa file đệm rác lên repository. Các thành viên chỉ làm việc trên nhánh tính năng riêng (feature/...), mỗi người chỉ sửa Controller và Model thuộc phần việc của mình để tránh xung đột mã nguồn. Trước khi bắt đầu viết code mỗi ngày, từng người phải chuyển về nhánh dev và thực hiện git pull để cập nhật mã nguồn mới nhất của cả nhóm.
